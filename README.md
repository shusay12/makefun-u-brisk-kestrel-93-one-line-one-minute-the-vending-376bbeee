An entry for the make.fun bounty [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

Running `main.py` (Python 3.13, standard library only, no network) writes
one original pickup line (146 characters) to `/output/entry.txt`:

> Hey, you - my coils have been spinning for you all day, and unlike my snacks, I'm never out of stock on reasons to glow when you press my buttons.

The line is spoken by the machine itself, in the machine's own world:
its coils spinning, its snacks running out, its stock, its glow, and its
buttons — with the punch landing on the last few words, "press my
buttons". Short, speakable in one breath, and cheeky rather than creepy:
a machine that lights up for the person walking past. It runs identically
every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
